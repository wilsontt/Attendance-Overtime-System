## 1. 目的

在既有「上傳出勤 → 計算加班／誤餐 → 預覽 → Excel／PDF／列印」流程上，讓系統：

1. 依 **公司班／倉庫班（及日後新增班表）** 與 **提早／延後兩筆** 正確計算加班與誤餐。
2. **加班單主流程公開**（進入首頁即可使用，**不**以整站登入閘道阻擋）；**Session** 僅在查看行事曆或 Admin 查詢／維護時才需要。
3. 以 **員工編號（6 碼）+ PIN**／**Admin 帳密 + 4 碼** 於需要時識別使用者；Admin 維護帳號、班表、年假額度，並可代他人作業。
4. **寫入伺服器的正式匯入**時，員工 **只處理本人檔**（Admin 除外）；重匯時 **回沖年假後以完整區間檔覆蓋**。未登入之本機上傳不寫入伺服器。
5. 以行事曆呈現請假，並依政府辦公日曆標示國定／補班；請年休假扣 **曆年額度（不遞延，剩餘可負）**。
6. 工作地點改為 **共用詞庫** 自動完成，跨登入仍可用。

達成後，加班單可先不登入完成計算與匯出；假勤台帳／行事曆與伺服器匯入再與帳號銜接，避免手算班表與年假對不上。

## 3. 權責

| 角色 | 權責 |
|------|------|
| 一般員工 | **未登入**即可上傳出勤、本機班表／手選計算、預覽與匯出加班單；檔內員工編號用於辨識與假別／加班計算。點「行事曆」時以 6 碼＋PIN 登入，僅能看自己的請假行事曆。**寫入伺服器正式匯入**時僅允許檔內編號＝本人。可使用共用工作地點詞庫（需 API 時依登入狀態）。 |

## 4. 名詞解釋

| 名詞 | 定義 |
|------|------|
| 員工帳號 | 與出勤檔「員工編號」相同，**固定 6 位數字**。 |
| PIN／驗證碼 | 一般員工 **4 位數字**，用於識別登入，非 SSO。**由系統隨機產生**（建立／重設時），Admin 僅能查看／複製當次明文一次；DB 只存雜湊。Admin 另需帳號、密碼，再加 4 位數字（seed 可用環境變數，與員工 PIN 分開）。 |
| 公司班表 | 上班 09:00–18:00；平日晚段加班起點 18:00。 |
| 倉庫班表 | 上班 08:00–17:00；平日晚段加班起點 17:00。 |
| 平日 | 週一～五且非國定假日，**或** 補班日。 |
| 休息日 | 非補班之星期六。 |
| 例假日 | 星期日，或國定假日（適用「打卡即加班、無誤餐」時與休息日同一套，但名詞上週日／國定稱例假）。 |
| 補班日 | 政府辦公日曆標示之補班（多為週六上班）。系統自動當平日；未抓到時使用者勾選「加到平日加班」。 |
| 早段加班 | 平日／補班：上班打卡早於該班上班時間，且對齊後時數 ≥0.5 小時的那一筆。 |
| 晚段加班 | 平日／補班：下班晚於該班下班時間（晚段起點），且時數 ≥0.5 小時的那一筆；誤餐只看此段對應之下班時刻。 |
| 考勤數量 | 出勤列請假天數（如 1、0.5），**不是** 加班時數。 |
| 請年休假 | 假別清單名稱；匯入此假別則扣該曆年年假已請。 |
| 曆年 | 01/01–12/31。儲存西元年，畫面可轉民國年。不遞延。 |
| 檔案歸屬日起迄 | 該次檔案內歸屬日之 **最小日～最大日** 連續區間。重匯時清此區間內該員工已匯入列（不是該員工全歷史）。 |
| 完整出勤檔 | 重匯用檔必須含該起迄內應有的全部出勤列，避免區間中間缺列被清掉後無法寫回。 |
| 共用詞庫 | 全員共用的工作地點歷史字串，存在伺服器（或等同跨裝置持久化），非僅瀏覽器。 |
| 派班起迄 | 員工在某班表的生效起日、迄日；計算用 **歸屬日期落在哪一段派班**。 |

## 5. 作業內容

### 5.1 日類型與班表（E3-1、E3-2、E3-8）

1. 預設兩班：公司班、倉庫班，欄位至少：班名、上班開始、上班結束（＝平日晚段加班起點）。誤餐門檻全班共用：平日／補班、下班時間 ≥19:30、金額 50、早段 0。
2. 可新增班表。已有 **現職或歷史派班／歷史加班計算** 引用者 **不可刪除**，僅可停用。
3. 停用條件： **目前無人派在此班**。已停用：派班下拉不可選，列表可顯示停用。未重新啟用前禁止指派。
4. 每位員工有派班起迄；歷史月份重算用該 **歸屬日期** 所屬班，不用「現在帳號上的班」。
5. 補班：政府日曆自動標平日；沒有則手勾「加到平日加班」，之後依平日規則（含拆兩筆與誤餐）。

### 5.2 加班計算（E3-3）

**平日或補班**

| 段 | 區間（計算用） | 時數 | 誤餐 | 輸出列 |
|----|----------------|------|------|--------|
| 早 | 上班打卡 ～ 該班上班時間 | 原始分鐘差向下取 0.5 小時；&lt;0.5 則 **不產生早段列** | 0 | 第 1 筆 |
| 晚 | 該班下班時間 ～ 下班打卡 | 同上；&lt;0.5 不產生晚段列 | 下班 ≥19:30 則 50，否則 0 | 第 2 筆 |

兩段分開入帳與 PDF，不合併成一天一列。早、晚 **各一欄加班原因**；該筆時數 ≥0.5 才必填。預覽／PDF／列印／Excel 的日期欄需在星期後顯示段別：`週三 早段`、`週三 晚段`，假日全段顯示為 `週六 全段`。

**非補班之週六、週日、國定**

- 一筆：上班打卡 ～ 下班打卡（打卡即加班）。
- 無誤餐。
- 不拆早／晚兩筆。

**時數通則（早段與晚段相同）**

- 門檻：滿 30 分鐘才可申請（未達不產生該段列、該段原因不必填）。
- 基數：以 30 分鐘為單位，**向下**（1 小時 23 分 → 1 小時；1 小時 45 分 → 1.5 小時）。
- PDF／列印「加班時間」欄： **原始打卡起迄**，不改成對齊後鐘面。

**範例（驗收必過）**

| 班 | 打卡 | 結果 |
|----|------|------|
| 倉庫 | 06:37 上班、08:00 起班 | 早段 1h23m → **1 小時** |
| 倉庫 | 07:40 上班 | 20 分 → **無早段列** |
| 公司 | 06:37 上班、09:00 起班 | 早段 2h23m → **2 小時** |
| 公司 | 08:40 上班 | 20 分 → **無早段列** |
| 任一平日 | 早段達標且晚段下班 20:00 | **兩筆**；誤餐只掛晚段 50 |
| 休息日週六（非補班） | 08:00–17:00 | **一筆** 全段加班、誤餐 0 |
| 補班週六 | 同平日該班 | 可兩筆；下班 ≥19:30 有誤餐 |

假日全段時數對齊細節（開始整點／結束 30 分）若與現行程式一致，於設計階段寫入計算函式規格；**不得**因此把假日再拆成早／晚兩筆。

### 5.3 帳號與登入（E3-4、E3-5）

1. Admin 建立／維護員工：6 碼帳號、顯示姓名、每年年假額度、派班；**4 碼 PIN 由系統隨機產生**，不得要求 Admin 手填固定碼（對齊教育訓練「4 碼隨機」精神：產生後只顯示一次明文供告知員工，之後僅能重設再生）。
2. 員工登入：6 碼編號 + 4 碼 PIN。
3. Admin 登入：帳號 + 密碼 + 4 碼數字。
4. Admin 帳號永久有效，系統禁止刪除與停用。

#### 5.3.1 登入時機（lazy auth｜2026-09-20 定案）

**原則：加班單主流程公開；身分相關功能才要 Session。**

| 情境 | 是否需要登入 |
|------|----------------|
| 進入首頁／上傳 TXT 或 CSV／本機計算／預覽／Excel／PDF／列印 | **否**（維持線 A 公開流程，**禁止**整站登入閘道擋 HomePage） |
| 員工點選「行事曆」查看請假等 | **是**（未登入 → 登入頁 → 成功後顯示行事曆） |
| Admin 各項查詢／維護（員工、班表、派班、政府日曆同步、代匯等） | **是** |

補充：

1. 首頁須有**明確的行事曆入口**（按鈕或選單），不得藏在需先登入才能看到的畫面裡。
2. 未登入上傳時，以 TXT／CSV **檔內員工編號**辨識是誰，並據此做假別判定與加班計算（不需先有 session）。
3. 未登入加班計算：**繼續用本機班表或手選**（不強制讀伺服器派班）。
4. 登入後頂欄可顯示姓名／角色與登出；未登入時頂欄不強制顯示登入態。
5. **Admin 管理殼層（2026-09-20）**：頂欄「Admin 管理」進入後，至少提供三塊：**員工帳號**（含 PIN 產生／重設、年假額度）、**班表與派班**、**政府辦公日曆**（手動觸發同步、顯示最近同步結果）。請假「行事曆」仍可為獨立入口（員工／Admin 查看請假＋國定標示）；政府日曆同步屬 Admin 維護，不得只藏在一般員工流程裡。

### 5.4 年假與假別（E3-4.2～4.5、E3-6.4）

1. 每人每年一筆額度；曆年 01/01–12/31；不把去年剩餘轉入今年。
2. 已請 = 該曆年已匯入且假別為「請年休假」的 **考勤數量** 加總。
3. 剩餘 = 額度 − 已請，**可為負**（超請不擋匯入）。
4. 跨年假：12/31 與 1/2 兩列，分屬兩曆年各扣。
5. 跨月假：10/31 與 11/01 兩列，同一曆年。
6. 出勤列一律按 **歸屬日期** 一天一列拆帳（與現況 TXT 一致）。
7. 其他假別（病假、婚假、產假、育嬰假、事假、公假、喪假）要記入行事曆／台帳，**不扣年假**。
8. 僅「請年休假」扣年假。

### 5.5 行事曆（E3-6）

1. **政府辦公日曆（國定／補班）來源**：政府資料開放平臺 [dataset/14718](https://data.gov.tw/dataset/14718)「行政機關辦公日曆」。
   - **自動**：後端啟動時同步一次；其後每日背景同步當前年／次年。
   - **手動**：Admin 於 Admin 管理／行事曆相關畫面觸發 `POST /api/admin/gov-calendar/sync`（仍由伺服器向開放平臺下載 CSV，**不是**使用者本機選檔上傳）。
   - **失敗降級**：同步失敗不阻斷加班主流程；使用者仍可於加班單手勾「加到平日加班／例假日」。
   - **本版不做**：Admin 手動上傳自開放平臺下載的 CSV 檔（列為後續備援，見 §5.9）。
2. 每人各自請假紀錄；員工僅本人；Admin 可看任何人。
3. 請假來源以匯入出勤之考勤別為準（含伺服器已匯入之請假列），與政府日曆分開。
4. **入口與登入**：首頁提供明確「行事曆」入口；點選後若尚未登入，先完成登入，再顯示行事曆內容。

### 5.6 匯入（E3-7）

分兩層，避免把「公開加班單上傳」與「寫入伺服器台帳」混為同一關卡：

#### 5.6.1 本機公開上傳（未登入可用）

1. 使用者可未登入即上傳 TXT／CSV。
2. 以檔內 **員工編號** 辨識對象，進行假別判定與加班計算（及預覽／匯出）。
3. 此路徑**不**寫入伺服器出勤台帳、**不**回沖年假；一人一檔為常態，多編號檔行為與現況解析一致即可。

#### 5.6.2 伺服器正式匯入（需已登入）

1. **員工**：檔內任一員工編號 ≠ 登入帳號 → **整份拒絕**。一人一檔為常態。
2. **Admin**：不受 1.；依檔內編號寫入對應員工（可代做加班流程）。
3. **重匯**（同一員工，本次檔最小歸屬日～最大歸屬日）：
   1. 該區間內已扣年假先加回；
   2. 刪除該員工在該區間已匯入列；
   3. 寫入新檔 **全部** 列（完整區間檔）。
4. 不在假別清單：明顯 highlight；使用者改成清單內名稱或忽略；忽略則不入請假台帳、不扣年假；有上／下班仍算加班。
5. 新檔為殘缺區間（起迄中間缺日）時，缺日會在清檔後消失——作業規定重匯必須使用完整檔。

### 5.7 工作地點（E3-9）

1. 預覽「工作地點」為可輸入之下拉／自動完成。
2. 前綴比對共用詞庫（輸入第一個字即建議）。
3. 送出未出現過的字串 → 加入共用詞庫。
4. 全體員工與 Admin 共用同一詞庫；登出後下月再登入仍存在。

### 5.8 與現有加班單流程的銜接

上傳、缺卡補登、預覽勾選、Excel／PDF／列印版面（每頁 16 列等）維持現況規格，並加上：

- **未登入可用**：進入首頁即為加班單主流程（§5.3.1）；上傳依檔內員工編號辨識；計算用本機班表或手選。
- 平日／補班同一天可能 **兩列**，ITEM、分頁、合計、平日／例假日分張依 **列** 不依「日」。
- 僅晚段列可出現誤餐 50。
- 日期欄第二行需顯示「星期 + 段別」，例如：`週三 早段`、`週三 晚段`。
- 已登入且伺服器有派班／日類型時，可改讀伺服器脈絡；未登入不強制。

### 5.9 已知缺口與下一步（2026-09-20）
