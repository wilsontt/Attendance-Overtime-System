# 其他假別（颱風假等）設計

> 狀態：**已實作**（2026-11-04）→ 計劃見 `plan-other-leave-summary.md`  
> 日期：2026-11-04  
> 來源對話：出勤異常報表含 `颱風假/n日`，不可併入公假；假勤摘要採固定「其他假別」卡。

## 1. 目的

讓來源出勤檔中**不在 §7.6 正式假別清單**的考勤別（例如颱風假，以及日後地震假、停班等）能：

1. 被正確解析並寫入台帳／本機加班單流程；
2. 全天者略過缺卡補登、不進加班計算；
3. 在請假行事曆「假勤摘要」以**固定一張「其他假別」卡片**加總與查明細，且明細列註明實際假別；
4. **不**與公假（教召、公出等）混計。

## 2. 範圍

### 2.1 納入

| 層級 | 內容 |
|------|------|
| 前端 TXT 解析 | 認 `假別名/數量日`（含清單外名稱，如颱風假） |
| 前端 CSV | 清單外考勤別改為可匯入（對齊後端未知假別），並 highlight |
| 加班單主列表 | 全天（數量 ≥ 1）含未知假別 → 略過缺卡；部分（&lt; 1）仍須出勤／補登 |
| API `GET /api/leave/summary` | 新增固定欄 `otherLeave.usedDays` |
| 行事曆假勤摘要 UI | 固定多一張「其他假別」卡；明細 Modal 多「假別」欄 |
| 契約／PRD／測試 | OpenAPI、§5.5.1／§7.6／§7.8、單元測試對齊 |

### 2.2 不納入（非目標）

- 不把「颱風假」等寫死進 §7.6 正式清單（避免每來一種就改白名單）。
- 不改政府辦公日曆同步邏輯（天災停班仍以出勤檔考勤別為準，不自動標國定）。
- 不拆公假子類（教召／公出仍屬公假）。
- 不改加班 PDF／Excel 版面列數規則。
- 不新增「時」為單位的解析（來源格式維持 `／n日`；不足一天以小數日表示，如 `0.5日`）。

### 2.3 反目標（做成這樣算失敗）

- 颱風假天數併入公假摘要。
- 未知假別完全無法略過全日缺卡，使用者只能假補打卡。
- 「其他假別」明細看不到實際假別名稱。

## 3. 權責

| 角色 | 責任 |
|------|------|
| 員工／使用者 | 上傳含颱風假等之出勤檔；部分天數缺卡時仍補登 |
| Admin | 代匯入台帳；查看任一員工「其他假別」摘要 |
| 系統 | 解析未知假別、摘要加總、全日免補登、明細標示假別 |
| 開發 | 依本設計更新契約、前後端、測試與主控文件 |

## 4. 名詞解釋

| 名詞 | 定義 |
|------|------|
| 正式假別清單（§7.6） | `請年休假`、`病假`、`婚假`、`產假`、`育嬰假`、`事假`、`公假`、`喪假` |
| 未知／其他假別 | 考勤別非空，且**不在**正式清單（例：`颱風假`） |
| 其他假別卡片 | 假勤摘要上**固定一張**卡，加總該曆年所有未知假別之 `leaveQuantity` |
| 全天請假 | 有考勤別（含未知）且 `leaveQuantity ≥ 1` → 略過缺卡、加班時數 0 |
| 部分請假 | 有考勤別且 `0 < leaveQuantity < 1` → **仍須出勤**；缺卡要補登／說明 |

## 5. 作業內容

### 5.1 已鎖定決策（來自需求對話）

1. **不標公假**；颱風假等與公假分開。
2. 假勤摘要採 **方案 B**：固定一張「其他假別」，明細註明假別。
3. **半天／幾小時**：仍視為須出勤，要補登／說明（對齊現有部分請假）。
4. 來源範例列：`颱風假/1日//…`，刷卡欄空白＋異常＝無實刷。

### 5.2 解析

- **前端 `txtParser`**：與後端對齊——先匹配正式清單 `假別/n日`；否則匹配 `([\u4e00-\u9fa5]{1,10})/(\d+(?:\.\d+)?)日`，排除「上班」「下班」，寫入 `attendanceType`＋`leaveQuantity`。
- **後端 TXT**：已有未知假別後備，維持；補測試案例 `颱風假/1日`。
- **前端 CSV**：取消「僅白名單否則 throw」；清單外名稱視為未知假別可匯入，UI highlight（對齊 PRD 未知假別行為）。**（建置者裁定）**

### 5.3 加班單缺卡

- 維持現有 `leaveQuantity >= 1` 全天略過邏輯；前提是解析成功寫入考勤別（本設計修 TXT 漏解析）。
- 部分天數：不放寬，缺卡仍擋預覽。

### 5.4 API：`GET /api/leave/summary`

在既有 `annualLeave`、`leaveTotals` 外新增：

```ts
otherLeave: {
  usedDays: number; // 該曆年所有未知假別 leaveQuantity 加總；無則 0
}
```

- `leaveTotals` 行為不變（正式假別未出現仍 0；**仍不含**未知）。
- `summarizeLeaveQuantities`：對 `unknownLeaveType === true`（或考勤別非空且不在清單）加總進 `otherLeave.usedDays`。

### 5.5 假勤摘要 UI

- 在既有 8 張卡（年假＋7 非年假）旁，**固定多一張「其他假別」**（無資料亦顯示 `0 天`）。
- 點擊開啟鎖定式 Modal，標題：`{year} 年 · 其他假別 請假明細`。
- 資料：`GET /api/attendance` 該曆年 → 前端過濾 **未知假別** 且 `leaveQuantity > 0`，依歸屬日期升序。
- 明細欄位：**歸屬日期、假別、數量、上班、下班**（比正式假別明細多「假別」）。
- 無資料：`本年度無其他假別紀錄`。

### 5.6 行事曆月表

- 維持現況：台帳有考勤別即顯示於當日（含颱風假）；不另開需求。

### 5.7 建置者裁定（可覆核）

| 項目 | 裁定 |
|------|------|
| CSV 未知假別 | 可匯入＋highlight，不拒絕整檔 |
| 「其他」加總 | 含數量小數（0.5 等）；僅加總未知，不含正式清單 |
| 卡片順序 | 正式假別卡之後、最後一張為「其他假別」 |
| 未知判定 | 與後端 `isUnknownLeaveType` 一致（非空且不在 §7.6） |

## 7. 使用表單（欄位說明）

### 7.1 假勤摘要・其他假別卡

| 欄位 | 說明 |
|------|------|
| 標題 | 固定「其他假別」 |
| 已請天數 | `otherLeave.usedDays`（該曆年未知假別數量加總） |

### 7.2 其他假別明細 Modal

| 欄位 | 說明 |
|------|------|
| 歸屬日期 | 西元＋星期X（與現有明細相同格式） |
| 假別 | 實際考勤別（如颱風假）；**必顯示** |
| 數量 | `leaveQuantity` |
| 上班／下班 | 台帳打卡；可空 |

### 7.3 出勤檔考勤別（補充）

| 例 | 數量 | 加班單行為 |
|----|------|------------|
| `颱風假/1日` | 1 | 全天：免補登、時數 0 |
| `颱風假/0.5日` | 0.5 | 部分：缺卡仍須補登 |
| 連多日 | 每日一列或各列數量 | 逐日依上表 |
